# Y&Y Creativos — Portafolio

Sitio estático para GitHub Pages.

## Publicar
1. Sube **el contenido de esta carpeta** a la raíz del repositorio (index.html debe quedar en la raíz).
2. Settings → Pages → Deploy from a branch → main → / (root).

## Contenido
- index.html — la página.
- support.js — runtime de la página.
- LandingPreview.dc.html — miniatura animada de las tarjetas.
- ds/ — estilos y tokens de marca (sin guion bajo, para que GitHub Pages no los ignore).
- assets/ — imágenes optimizadas.
- .nojekyll — importante: evita que GitHub Pages procese los archivos.
